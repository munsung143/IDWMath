## 수집합의 종류

소박한 집합론(Native set theory)에 따라 수를 다음과 같이 구분 가능하다.

자연수(Natural)  
$\mathbb{N} = \{1,2,3,\ldots\}$  
$\mathbb{N}_0 = \{0,1,2,3,\ldots\}$  

정수(Integer)  
$\mathbb{Z} = \{\ldots,-3,-2,-1,0,1,2,3,\ldots\}$  
$\mathbb{Z}^+ = \{1,2,3,\ldots\}$  
$\mathbb{Z}^- = \{\ldots,-3,-2,-1\}$  
$\mathbb{Z}_{\leq0} = \{0,1,2,3,\ldots\}$  
$\mathbb{Z}_{\geq0} = \{\ldots,-3,-2,-1,0\}$  

유리수(Rational)  
분모가 0이 아닌 두 정수의 비율(분수)로 나타낼 수 있는 수의 집합  
$\mathbb{Q} = \left\{ \frac{p}{q} \;\middle\vert{}\; p, q \in \mathbb{Z} \land q \neq 0 \right\}$

무리수(Irrational)  
유리수로 나타낼 수 없는 수의 집합  
$\mathbb{I} = \{\sqrt{3},\pi,\sin{15\degree},\ldots\}$

실수(Real)  
유리수와 무리수를 포함하는 수의 집합  
$\mathbb{R} = \mathbb{Q} \cup \mathbb{I}$

복소수(Complex)  
허수단위 $i$와 실수를 조합한 수의 잡합  
$\mathbb{C} = \{a+bi \;\vert{}\; a,b \in \mathbb{R}\}$  


복소수의 실수부와 허수부 값에 따라 다음과 같이 구분된다.  
$a=0 \land b = 0$ : 0  
$a=0 \land b \neq 0$ : 순허수  
$a \neq 0 \land b = 0$ :  0을 제외한 실수  
$a \neq 0 \land b \neq 0$ : 순허수도 실수도 아닌 복소수  

수집합 간의 관계  
$\mathbb{N} \subset \mathbb{Z} \subset \mathbb{Q} \subset \mathbb{R} \subset \mathbb{C}$  
$\mathbb{I} = \mathbb{R} - \mathbb{Q}$  

이 외에도 다양한 유형의 수집합을 정의할 수 있다.  
짝수, 홀수, 소수, 정수가 아닌 유리수 등

## 연산과 수의 구조
공리(Axiom) : 증명할 필요가 없는 기본 명제  
공리적 집합론(Axiomatic set theory) : 공리를 기반으로 대상을 구분하는 집합론  
이항연산(Binary operation) : 수집합에서, 두 개의 원소를 사용해 새로운 원소를 만드는 과정

이항연산의 성질  
- 닫혀 있음(Closure) : 같은 집합에 속한 두 원소의 연산 결과가 동일한 집합에 속한다.
$$
X \neq \varnothing \\
\forall a,b \in X,\; a*b \in X
\implies
X \text{ is closed under } *
$$
- 교환 법칙(Commutative law) : 두 원소의 연산 순서에 상관없이 동일한 결과가 나온다.
- 결합 법칙(Associative law) : 같은 연산이 두 번 이상 연속될 때, 앞 뒤 연산 순서에 상관없이 동일한 결과가 나온다.
- 분배 법칙(Distributive law) : 서로 다른 두 연산에 대하여 좌분배법칙 및 우분배법칙이 성립한다.  
$$
\begin{aligned}
&\text{left :} \;a*(b+c)=a*b+a*c\\
&\text{right :} \;(b+c)*a = b*a +c*a
\end{aligned}
$$
- 항등원(Identity) : 임의 원소와의 연산 결과를 항상 동일한 원소로 만들어주는 특별한 원소  
예:  
  - 덧셈의 항등원은 0이다.
  - 곱셈의 항등원은 1이다.  
- 역원(Inverse) : 임의 원소와의 연산 결과를 항상 항등원으로 만들어 주는 특별한 원소  
예:
  - 덧셈의 역원은 부호가 반대인 반대수(Opposite number)다.
  - 곱셈의 역원은 역수(Reciprocal)다.

군(Group)  
정의된 이항연산에 대하여 다음 조건을 모두 만족하는 집합은 군의 구조를 가진다고 표현한다.
1. 닫혀 있음
1. 결합법칙 성립
2. 항등원의 존재
3. 역원의 존재

아벨군(Abelian) 또는 가환군(Commutative)  
군에 대하여 다음 조건을 만족한다.
1. 교환법칙 성립

환(Ring)  
이미 덧셈에 대한 아벨군 구조를 가지는 집합에서, 곱셈에 대하여 다음을 만족한다
1. 닫혀 있음
1. 곱셈 결합법칙 성립
2. 분배법칙 성립

가환환(Commutative)  
환에 대하여 다음이 성립한다.
1. 곱섬에 대한 교환법칙

단위원을 갖는 환(Ring with Identity)  
환에 대하여 다음이 성립한다.
1. 곱셈에 대한 항등원의 존재

체(Field)  
단위원을 갖는 가환환에 대하여 다음이 성립한다.
1. 곱셈 역원의 존재 (0 제외)

즉 체의 경우 덧셈과 곱셈에 대한 교환, 결합 및 항등원과 역원이 각각 존재하고, 서로간 분배법칙이 성립한다.  
유리수 집합과 실수 집합은 덧셈과 곱셈에 대하여 체의 구조를 가진다.  
즉 일반적인 사칙연산이 자유롭게 수행될 수 있음을 의미한다. (뺄셈은 덧셈의 역원을, 나눗셈은 곱셈의 역원을 사용한다)

## 함수
첫 번째 집합의 모든 원소가 두 번째 집합의 어떤 원소에 하나씩 대응되는 관계

전사함수(Surjection)  
$\text{Codomain} = \text{Range}$

단사함수(Injection)

전사이면서 단사인 함수

### 합성합수와 역함수, 이항연산적 관점
두 함수의 합성을 이항연산적으로 볼 수 있다.  
다음과 같은 대응 관계에 대하여,
$$W \to X \to Y \to Z \\ f(w)=x \\ g(x)=y \\ h(y)=z$$
최종적으로 $W \to Z$ 관계를 만들기 위해 두 번의 함성이 필요하다.  
이때 앞에 두 함수를 먼저 합성하건, 뒤의 두 함수를 먼저하건, 최종적인 결과에는 차이가 없다.
$$g(f(w))=y,\; h(y)=z \\ h(g(f(w)))=z \\  f(w)=x,\; h(g(x))=z \\ h(g(f(w)))=z$$
$$\therefore (h \circ (g \circ f))(w) = ((h \circ g) \circ f)(w)$$
이를 함수 합성 간 결합법칙이 성립한다고 볼 수 있다.  

항등함수(Identify function)  
만약 함수 합성에 대한 항등원 $id$가 존재한다면,  
$$f \circ id = f \\ \; id \circ f = f$$
가 될 것이다.  
이 역할을 하는게 항등함수이며, 대응 전과 후의 값 차이가 없는 함수이다.  
즉 똑같은 두 집합에서 화살표가 그대로 쭉 가는 모양.

역함수(Inverse function)  
$f:X \to Y$ 이후 $g: Y \to Z$ 를 하였을 때, $id: X \to Z$ 가 된다면, 그리고  
$g:X \to Y$ 이후 $f: Y \to Z$ 를 하였을 때, $id: X \to Z$ 가 된다면,  
$f, g$ 는 서로가 서로에 대한 역원이 되고, 이때 역함수 $g = f^{-1}$ 로 표현한다.
$$f \circ f^{-1} = id \\ \; f^{-1} \circ f = id$$

역함수는 정의역에서 공역으로 가는 화살표의 방향을 반대로 바꾼 관계다.
이를 잘 떠올려 보면 왜 전단사 함수만이 역원을 가질 수 있는지 직관적으로 알 수 있다.  

역함수가 기본적으로 되돌아 가며 대응시키는 과정이라는 점에서, 다음이 성립함을 알 수 있다.  
$f$를 통해 이동 후 $g$를 통해 이동하는 과정의 반대는, $g$를 거스른 이후 $f$를 거스르는 것이다.
$$(g \circ f)^{-1} = f^{-1} \circ g^{-1}$$

정리해보면, 모든 전단사함수의 집합 $F$ 는 합성연산 $\circ$ 에 대한 군(Group)을 이룬다고 볼 수 있다.

## 벡터 공간

데카르트 좌표계  
실수의 곱집합 $\mathbb{R} \times \mathbb{R}$ 의 순서쌍 원소를 수직적으로 배치해 표기하는 방식.  
두 번 곱하면 평면, 세 번 곱하면 공간에 배치 가능.

스칼라(Scalar)  
체의 구조를 가지는 수 집합의 원소. 대표적으로 실수

벡터 공간(Vector space) $V$  
두 개 이상 실수를 곱하여 형성된 집합을 공리적 집합론의 관점에서 규정한 것.  
벡터 공간의 원소는 벡터이다. $\vec{v}=(x,y)$  
제대로 이해되지는 않지만, 결국 벡터 공간 내의 원소들 즉 벡터 또한 스칼라로 이루어져 있고,  
이 벡터(스칼라,스칼라)와 스칼라 사이의 연산에 대하여 추가적인 8가지 공리를 만족하는 집합을 벡터 공간으로 간주한다고 보는 것 같다.  

벡터 공간의 8공리
1. 벡터간 합에 대한 결합법칙 성립
   $$\vec{u}+(\vec{v}+\vec{w})=(\vec{u}+\vec{v})+\vec{w}$$
2. 벡터간 합에 대한 교환법칙 성립
   $$\vec{u}+\vec{v}=\vec{v}+\vec{u}$$
3. 벡터간 합에 대한 항등원 존재
   $$\vec{v}+\vec{0}=\vec{v}$$
4. 벡터간 합에 대한 역원 존재
   $$\vec{v}+(-\vec{v})=\vec{0}$$
5. 스칼라 곱셈에 대한 호환성
   $$a(b\vec{v})=(ab)\vec{v}$$
6. 스칼라 곱셈에 대한 항등원 존재
   $$1\cdot \vec{v}=\vec{v}$$
7. 벡터 합에 대한 분배법칙 성립
   $$a(\vec{u}+\vec{v})=a\vec{u}+a\vec{v}$$
8. 스칼라 합에 대한 분배법칙 성립
   $$(a+b)\vec{v}=a\vec{v}+b\vec{v}$$


즉 벡터 라는 원소가 들어 있는 집합이 있고, 이것과 스칼라 사이의 연산에 대한 8가지 공리가 성립한다면,  
그 벡터가 뭐든 간에 이것이 들어있는 집합이 벡터 공간으로 간주된다는 의미다.  
다만 스칼라와의 호환성을 위해 여기서 벡터를 스칼라의 순서쌍으로,  
그리고 연산을 다음과 같이 정의함으로서 8가지 공리를 만족하도록 설계한 것이다.
$$\vec{v_1}+\vec{v_2} = (x_1+x_2, y_1+y_2)\\a \cdot \vec{v} = (ax_1,ay_1)$$

	auto& g = Get2DGameEngine();
	const InputManager& input = g.GetInputManager();

	// 정규화된 입력 방향으로 델타타임, 스피드 만큼 반영하여 위치 업데이트
	static float moveSpeed = 100.f;
	Vector2 inputVector = Vector2(input.GetAxis(InputAxis::XAxis), input.GetAxis(InputAxis::YAxis)).GetNormalize();	
	Vector2 deltaPosition = inputVector * moveSpeed * InDeltaSeconds;
	currentPosition += deltaPosition;
}

// 렌더링 로직
void SoftRenderer::Render2D()
{
	// 렌더러 및 엔진 모듈 참조
	auto& r = GetRenderer();
	const auto& g = Get2DGameEngine();

	// 배경에 격자 그리기
	DrawGizmo2D();

	// currentPosition 과 원점을 지나는 긴 회색 선을 그린다
	static float lineLength = 500.f;
	Vector2 lineStart = currentPosition * lineLength;
	Vector2 lineEnd = currentPosition * -lineLength;
	r.DrawLine(lineStart, lineEnd, LinearColor::LightGray);

	// 원의 반지름 및 칠할 위치의 좌표들
	static float radius = 50.f;
	static std::vector<Vector2> circles;

	// 원에 외접하는 정사각형 영역을 돌며
	// 원의 부등식에 성립하는지를 조사하고,
	// 성립한다면 추가한다.
	if (circles.empty())
	{
		for (float x = -radius; x <= radius; ++x)
		{
			for (float y = -radius; y <= radius; ++y)
			{
				Vector2 pointToTest = Vector2(x, y);
				float squaredLength = pointToTest.SizeSquared();
				if (squaredLength <= radius * radius)
				{
					circles.push_back(Vector2(x, y));
				}
			}
		}
	}

	// 중심 위치 만큼 더하여 붉은색으로 출력.
	for (auto const& v : circles)
	{
		r.DrawPoint(v + currentPosition, LinearColor::Red);
	}

	// 벡터의 현재 좌표를 우상단에 출력
	r.PushStatisticText("Coordinate : " + currentPosition.ToString());
}

## 벡터의 결합과 생성

벡터 공간의 벡터의 합과 스칼라 곱셈 연산은 '선형성'을 가진다.

선형 결합(Linear combination)  
$n$개의 스칼라와 $n$개의 벡터를 결합(합,곱)하여 새로운 벡터를 생성  
$a_1\vec{v_1}+a_2\vec{v_2}+a_3\vec{v_3}+\dotsi+a_n\vec{v_n}=\vec{v'}$

선형 종속 관계
선형 결합의 모든 스칼라의 값이 0이 아님에도 $\vec{0}$를 만들 수 있다면,
여기에 사용된 모든 벡터는 서로 선형 종속 관계를 가진다. 

선형 독립 관계
선형 결합의 모든 스칼라의 값이 0인 경우에만 $\vec{0}$를 만들 수 있다면,
여기에 사용된 모든 벡터는 서로 선형 독립 관계를 가진다. 

선형 독립인 벡터를 적절한 스칼라값으로 선형 결합하면,
벡터 공간에 속한 모든 벡터를 만들 수 있음을 연립방정식을 통해 알 수 있다.
2차원 벡터에서의 예시
$$(w_x,w_y) = a(u_x,u_y)+b(v_x,v_y) \\ au_x+bv_x=w_x \\ au_y+bv_y=w_y \\ 
a = \frac{w_xv_y-w_yv_x}{u_xv_y-u_yv_x} ,\;
b = \frac{u_xw_y-u_yw_x}{u_xv_y-u_yv_x}
$$
이때 분모 $u_xw_y-u_yw_x$는 두 벡터의 비례식으로, 서로 비례하여 0이 되는 경우, 즉 서로가 종속인 경우는 위의 식이 성립하지 않는다.
분자의 $w_x,w_y$가 모두 0일 때 $a,b$ 또한 0으로 귀결된다.

세 개 이상의 2차원 벡터의 경우, 서로 선형 독립 관계가 될 수 없다.
앞선 벡터가 독립일 경우, 항상 결합하여 뒤 벡터와 반대 방향을 가지는 벡터를 만들 수 있기 때문.
이러면 $c=0$ 이 아니어도 영벡터가 만들어진다.
$$a\vec{x}+b\vec{y}+c\vec{z} = \vec{0} \\ -c\vec{z}+c\vec{z}= \vec{0}$$

기저(Basis)
어떤 벡터 공간 내 모든 벡터를 만들어 낼 수 있는(선형 독립 관계를 가지는)벡터들의 집합.
이 집합의 벡터를 기저 벡터(Basis vector)라고 한다.
$B=\{(1,0),(0,1)\}$
은 평면 벡터공간의 기저 중 하나이고, 평면 벡터공간의 기저는 언제나 2개의 원소를 가진다.
위와 같이 한 축만을 사용하는 단위벡터고 구성된 기저는 특별히 표준기저(Standard basis)라고 한다.
$e_1=(1,0),\;e_2=(0,1)$ 로 나타낸다.

차원(Dimension)
어떤 벡터 공간을 형성하는 기저의 원소의 개수.
실수의 곱집합으로 생성한 벡터 공간을 실벡터 공간(Real vector space)으로 부르며
$\mathbb{R}^2,\mathbb{R}^3,\mathbb{R}^4$ 등으로 나타낸다.

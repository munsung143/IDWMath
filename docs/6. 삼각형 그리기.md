## 컨벡스 결합
결합하는 모든 점의 계수의 합이 1이 되어야 하는 아핀 결합의 조건에, 모든 계수가 $[0,1]$ 의 범위를 가지도록 제한하는 결합.

두 점을 단순히 아핀 결합 하는 경우에는 두 점을 지나는 직선이 얻어지지만,
두 점을 컨벡스 결합할 경우 두 점을 잇는 선분이 얻어진다.
$$(1-a)P_1+aP_2=P' \\
\longrightarrow \\
a(P_2-P_1)=P'-P_1 \\
\longrightarrow \\
a\vec{v}=\vec{u}$$
마지막 식은 두번째 식을 간단히 나타낸 것이다.
구하려는 점 $P'$ 와는 별개로, 결과가 하나의 벡터 즉 직선 위에서만 논다는 사실을 보여준다.

만약 두 점과 선분 사이의 삼각형 영역을 얻고자 한다면 다음과 같이 세 점을 컨벡스 결합해주면 된다.
$$sP_1+tP_2+(1-s-t)\vec{0} \\ \vec{0}=(0,0,1),\;(0\leq s,t\leq 1)$$
부족한 값을 마지막 영점의 계수에서 보충해 주기 때문에, $0 \leq s+t\leq1$ 이 되도록 두 값을 비교적 자유롭게 설정하여 삼각형 영역을 얻을 수 있다.

마지막 점을 영점이 아닌 임의의 점으로 설정할 경우, 식은 다음과 같아진다.
$$sP_1+tP_2+(1-s-t)P_3 = P' \\
\longrightarrow \\
s(P_1-P_3)+t(P_2-P_3) = P'-P_3 \\
\longrightarrow \\
s\vec{u}+t\vec{v}=\vec{w}$$

마지막 식에서 알 수 있듯이, 결과는 어떤 면이 될 것 같다.

$s,t=0$ 이면, 계수1이 $P_3$ 쪽에 몰려서 결과는 $P_3$이 된다.
$s+t=1$ 이면, $P_3$의 계수는 0이 된다. 즉 일반적인 $P_1,P_2$을 잇는 선분이 된다.
$s=0$이면, 사실상 $P_2,P_3$을 컨벡스 결합한 선분과 같다.
$t=0$이면, 사실상 $P_1,P_3$을 컨벡스 결합한 선분과 같다.

위와 같은 경곗값 테스트를 통해 $P_1,P_2,P_3$을 꼭짓점으로 가지는 삼각형 영역이 얻어짐을 유추할 수 있다.

이렇게 만들어진 영역을 컨벡스 영역(Convex region)이라고 한다.
볼록한 영역이라는 의미로, 도형이 안쪽으로 음푹 들어가 있지 않은 형태이다.
즉 영역 내 두 점을 있는 선분을 그었을 때 해당 선분이 절대 영역 밖으로 나가지 않는 형태를 의미한다.
반대는 오목(Concave)하다고 한다.

만약 4개의 점을 컨벡스 결합할 경우,
독립하는 세 벡터의 결합이 3차원 공간을 이루는 것에서 유추할 수 있듯이, 삼각뿔의 형태가 된다.
$$\vec{x}=a\vec{u}+b\vec{v}+c\vec{w}$$

## 메시
메시(Mesh) : 삼각형으로 이루어진 입체를 표현하는데에 필요한 정점 데이터의 모음
정점(Vertex) : 점의 위치와 노멀, UV 등 부가 정보를 묶은 데이터
정점 버퍼 : 메모리에 정점 데이터들을 배열의 형태로 저장한 것
인덱스 버퍼 : 몇 번 째의 세 정점을 모아야 하나의 삼각형이 되는지에 대한 정보를 담은 배열. 항상 3의 배수 크기다.
와이어프레임(Wireframe) : 삼각형의 외곽선만으로 메시를 표현하는 방법

(삼각형 만으로 어떠한 입체든 분할하여 표현 가능한 이유)
이 부분은 뇌피셜인데, 우선 4개의 점으로 삼각뿔이, 그리고 이 주변에 하나의 점이 더 주어질 경우, 새로운 삼각뿔을 만들어서 붙여줄 수 있다. 이런 과정을 계속 반복할 경우 수많은 삼각뿔이 붙어서 외면이 삼각형으로 이루어져 있는 입체가 만들어지게 된다. 어떤 입체의 표면에 단순히 점을 콕콕 찍는 방식으로 정점을 얻을 수 있고, 이걸 삼각뿔로 이어붙여주기만 하면 되기 때문에, 삼각형만으로 입체를 표현 가능하게 된다.

두 개의 삼각형으로 이루어진 사각형 와이어프레임을 그리는 의사코드는 다음과 같다.
```cpp
// 각 위치 정보를 가지는 정점들
Vertex v1 = Vertex(-0.5, -0.5);
Vertex v2 = Vertex(-0.5, 0.5);
Vertex v3 = Vertex(0.5, 0.5);
Vertex v4 = Vertex(0.5, -0.5);

int vertexCount = 4; // 정점의 개수
int triangleCount = 2; // 그릴 삼각형의 개수
Vertexs rawVertices[vertexCount] = {v1,v2,v3,v4}; // 정점을 담은 배열
int indices[trigangleCount * 3] = {0,1,2,    0,2,3}; // 삼각형을 구성할 정점의 인덱스를 담은 배열

Mat3x3 M; // 회전, 이동, 스케일 변환을 수행하는 행렬이라고 가정

Vertexs vertices[vertexCount]; // 변환된 정점들을 담을 배열
for (int i = 0; i < vertexCount; i++){
  vertices[i] = M * rawVerticies[i]; // 변환
}

// 삼각형의 개수만큼 반복하며, 각 반복당 3개의 선분을 그린다.
for (int i = 0; i < triangleCount; i++){
  int bi = i * 3 // 0 3 6 9 ...
  DrawLine(verticies[indices[bi]], verticies[indices[bi + 1]]); // 0---1
  DrawLine(verticies[indices[bi]], verticies[indices[bi + 2]]); // 0---2
  DrawLine(verticies[indices[bi + 1]], verticies[indices[bi + 2]]); // 1---2
}
```

## 무게중심좌표
위의 아핀 결합을 구성하는 세 값 $(s,t,1-s-t)$ 모두가 $[0,1]$영역 내에 있어야 컨벡스 결합 되어 점들이 삼각형을 구성한다. 이 범위를 벗어난다는 것은 곧 점이 삼각형을 벗어남을 의미한다.
즉 위의 세 값을 각각 구하여 해당 점이 삼각형 안에 드는지를 확인할 수 있으며, 이 세 값으로 구성된 좌표를 무게중심좌표라고 한다.

위의 $P_3$에서 각 $P_1,P_2$를 향하는 벡터의 결합으로 $P'$으로 향하는 벡터를 생성하는 식은 다음과 같았다.
$$s\vec{u}+t\vec{v}=\vec{w}$$
위 식의 양변에 $\vec{u},\vec{v}$를 각각 내적한 두 식을 정리 후, 서로 연립하여 $s,t$를 각자 소거시키면 다음 식을 얻을 수 있다.

$$
s=\frac{(\vec{w}\vec{u})(\vec{u}\vec{v})-(\vec{w}\vec{v})(\vec{u}\vec{u})}{(\vec{u}\vec{v})^2-(\vec{u}\vec{u})(\vec{v}\vec{v})} \\\;\\
t=\frac{(\vec{w}\vec{v})(\vec{u}\vec{v})-(\vec{w}\vec{u})(\vec{v}\vec{v})}{(\vec{u}\vec{v})^2-(\vec{u}\vec{u})(\vec{v}\vec{v})} \\
$$

분모가 0이 되는 경우에는 확인이 불가능한데, 이는 곧 두 벡터가 영벡터거나,
 서로 평행하여 종속되는 경우라는 점을 다음과 같이 내적 식을 변환하여 확인 가능하다.
이렇게 선분이 되는 경우를 퇴화삼각형이라고 하며, 렌더링 대상에서 제외한다.
$$(\vec{u}\vec{v})^2-(\vec{u}\vec{u})(\vec{v}\vec{v})=|\vec{u}|^2|\vec{v}|^2\cos\theta - |\vec{u}|^2|\vec{v}|^2 = a\cos\theta - a$$

삼각형을 렌더링할때는 삼각형을 감싸는 사각형의 좌하, 우상 좌표에 대한 스크린 좌표를 구하고, 그 내부 픽셀들을 순회하며, 각 픽셀의 좌표를 카타시안으로 변환, $\vec{w}$ 벡터를 구하고, 위의 식을 적용하여 픽셀 렌더링 여부를 결정한다.

위의 의사코드에서 삼각형 렌더링 부분만 다음과 같이 바꾼다.
```cpp

for (int i = 0; i < triangleCount; i++){
  int bi = i * 3 // 0 3 6 9 ...
  Vertexs tv[3] = {verticies[bi], verticies[bi + 1], verticies[bi + 2]};
  vec2 minPos(Min(tv[0].x, tv[1].x, tv[2].x), Min(tv[0].y, tv[1].y, tv[2].y));
  vec2 maxPos(Max(tv[0].x, tv[1].x, tv[2].x), Max(tv[0].y, tv[1].y, tv[2].y));

  vec2 u = tv[1] - tv[0];
  vec2 v = tv[2] - tv[0];

  float uv = Dot(u, v);
  float vv = Dot(v, v);
  float uu = Dot(u, u);

  float denom = uv*uv - vv*uu; // 분모 계산

  if (denom == 0) continue; // 퇴화삼각형 제외

  ScreenPoint lowLeft = ToScreenCoord(minPos);
  ScreenPoint upRight = ToScreenCoord(maxPos);

  // 사각형 영역 클리핑 (최적화용)
  lowLeft.x = Max(0, lewLeft.x);
  upRight.x = Min(screensize.x, lewLeft.x);
  lowLeft.y = Min(screensize.y, lewLeft.y);
  upRight.y = Min(0, upRight.y);

  // 사각형 영역 순회
  for(int x = lowLeft.x; x <= upRight.x; x++){
    for(int y = upRight.y; y <= lowLeft.y; y++){

      // 스크린 - 일반 좌표계 변환
      vec2 point = ToCartesian(x, y);
      vec2 w = point - tv[0]; // w 벡터 계산

      // 내적 계산
      float wu = Dot(w,u);
      float wv = Dot(w,v);

      // s,t, 1-s-t 계산
      float s = (wv*uv - wu*vv) / denom;
      float t = (wu*uv - wv*uu) / denom;
      float omst = 1 - s - t;
      
      // 컨벡스 조건 확인 후 픽셀 그리기
      if(s>=0 && s<=1 && t>=0 && t<=1 && omst>=0 && omst<=1)
        DrawPoint(x,y);
    }
  }
}
```

무게중심좌표는 그 자체로 현재 어느 점에 가깝게 있는지에 대한 정보를 가지고 있다.
즉 위 식을 기준으로 $s$가 클 수록 점이 $P_1$ 쪽에 있다는 것이고,
$(0.333, 0.333,0,333)$ 의 값을 가진다면, 세 점의 영향을 동등하게 받는 무게중심점이 된다는 의미다.

각 정점에 색상 정보를 넣고, 랜더링 시
```
finalColor = P1.color * s + P2.color * t + P3.color * (1-s-t);
DrawPoint(x, y, flnalColor);
```
로 계산된 색상을 출력한다면, 해당 점의 영향권을 많이 받을수록 그 색상이 강해지도록 그라데이션 효과가 연출된다.

## 텍스쳐 매핑
텍스처 매핑 시에도 마찬가지로 정점의 UV를 위와 같은 식으로 보간해서 타겟 UV를 구한 후 텍스처에서 해당 UV에 맞는 색상을 적용한다.
```
vec2 targetUV = P1.uv * s + P2.uv * t + P3.uv * (1-s-t);
Color color = texture.getColor(targetUV);
DrawPoint(x, y, color);
```
